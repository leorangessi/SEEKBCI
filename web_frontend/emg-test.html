左柱 · Norm（OpenBCI EmgSettings）

影响：左侧彩色柱高度、文本 norm、avg|µV|、综合「驱动」中的 norm 分量。
不影响：右侧橙柱、峰/谷、bin 达标段数。

→ 参与平均的 |µV| 样本时长；窗越长 norm 越平滑、反应越慢。

→ norm 超过该值才计入「驱动」；与公式内上/下阈无关。

未勾选时行为与原先完全一致（自适应阈 + 可点下方重置）。勾选后 norm 按你填的 µV 上/下阈计算。

→ 公式中的「上阈」；avg|µV| 接近该值时 norm→1。柱内上横线位置。

→ 公式中的「下阈」；avg|µV| 接近该值时 norm→0。须小于上阈（至少相隔 10 µV）。

→ 仅未勾选固定阈时有效：恢复自适应初始值（上约 25 µV、下约 0 µV）。

右柱 · Bin 检测

影响：右侧橙柱高度、峰/谷 旁阈、bin a/b需/c段、是否显示「触发」、摇杆预览。
不影响：左侧 norm 柱高度与 norm 数值。

→ 统计最近多少秒内的 bin；越长可融合的段数越多（段数 = 窗长÷0.2）。

→ 每 0.2 s 段内 max/min 相对该阈判定是否「本段达标」；阈越高越难触发。

→ 单段幅值映射到橙柱 0～1 的上限；不改变达标段数，只改变柱高刻度。

→ 检测窗内至少多少比例的 0.2 s 段达标才算「bin 触发」（见右侧 b「需」）。

→ 仅本页摇杆预览：驱动需维持多久；刺激运行另有「触发驱动门限」等配置。

运动通道条形图

左柱（通道色，每路颜色不同）

  • 柱高 = norm（0～1），OpenBCI EmgSettings 算法。
  • 计算：对滤波后 |µV| 做滑动平均得 avg|µV|，再映射
    norm = (avg|µV| − 下阈) / (上阈 − 下阈)。
  • 默认上/下阈自适应（深色横线会动）；勾选「固定上/下阈」后改为手动 µV。
  • 深色横线 = 当前上/下阈；红虚线 = norm 驱动门限。
  • 调 norm：滑动窗长、固定上/下阈（可选）、norm 驱动门限；自适应模式下可「重置」。

右柱（橙色）

  • 柱高 = 驱动（0～1），用于触发与摇杆；取 norm 分量与 bin 分量的较大值。
  • Bin 检测：检测窗按 0.2 s 切段；单段达标条件：
    峰峰值 ≥ 2×阈，或（峰 > 阈 且 谷 < −阈）。
  • 文本 峰/谷 = 最近 0.2 s 段的 max/min；(±阈) = 当前波峰/波谷阈。
  • bin a/b需/c段：a 段达标，b 段达标即触发，共 c 段（非必须 a=c）。
  • 调 bin：改检测窗长、波峰/波谷阈、达标比例、力度上限。
