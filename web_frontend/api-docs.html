API 文档

物理世界控制 API

SEEKBCI PLAT 通过统一 API 控制 SEEKPHY BLE 设备、物联网平台设备和运动设备。工程编辑器只绑定统一设备与动作，底层由 BLE / 物联网平台 / MQTT / WebSocket 等适配器执行。

SEEKPHY BLEULID deviceId陀螺仪小车物联网平台接入

1. SEEKPHY BLE 协议协商

  1. 设备广播 SEEKPHY Control Service UUID，广播名建议 SEEKPHY-xxxx。
  2. 平台连接后读取 Device Info，获得 apiVersion、deviceUid、deviceType、capabilities、safety。
  3. 平台检查版本兼容，生成 dev_ + ULID 作为平台内 deviceId。
  4. 用户设置 name、alias、room、riskLevel 后注册。
  5. 平台写 Command，设备通过 State / Result Notify 回报。
Service: 7f510001-1b15-4a0b-9f7f-8f54f8d7a001 Info: 7f510002-1b15-4a0b-9f7f-8f54f8d7a001 Read State: 7f510003-1b15-4a0b-9f7f-8f54f8d7a001 Read / Notify Command: 7f510004-1b15-4a0b-9f7f-8f54f8d7a001 Write Result: 7f510005-1b15-4a0b-9f7f-8f54f8d7a001 Notify Heartbeat: 7f510006-1b15-4a0b-9f7f-8f54f8d7a001 Write / Notify Safety: 7f510007-1b15-4a0b-9f7f-8f54f8d7a001 Read / Write

3. 用户可调用 API

接口用途
GET /api/physical-world/devices获取已注册外部设备
POST /api/physical-world/discovery/ble/start扫描 SEEKPHY BLE 设备
POST /api/physical-world/discovered-devices/{discoveryId}/register注册扫描到的设备
POST /api/physical-world/iot-platforms添加物联网平台接入
POST /api/physical-world/iot-platforms/{platformId}/scan扫描平台实体/设备
POST /api/physical-world/control-bindings创建控制绑定，如陀螺仪→小车
POST /api/physical-world/commands发送统一控制命令
POST /api/physical-world/emergency-stop急停
