      SEEKPHY 设备

      使用我们固件的 BLE 外设，统一称为 SEEKPHY。

      BLE 扫描注册读取 Device Info统一 Command/State
      • 灯、继电器、门禁、传感器
      • 低速小车、简单执行器
      • 平台生成 ULID 作为 deviceId

      IMU 协议 seekbci_imu_v1

      BMI270 @ ESP32：ASCII ax,ay,az,gx,gy,gz（m/s² + rad/s）。

      BLE Nordic UARTHEAD_MODE光标 / 地球
      • 设备名 ESP32_BMI270_MOUSE
      • 校准：静止估零偏 + 重力轴
      • 二维光标 · 三维地球测试页

      项目编辑器绑定

      SSVEP / EMG / EOG / IMU 可在项目里绑定到被控设备动作。

      设备动作陀螺仪小车高风险确认
      • SSVEP 目标 → 开灯 / 关灯 / 场景
      • IMU pitch/roll → 小车速度控制
      • EMG 确认，EOG 急停 / 取消

      当前设备管理能力

      • IMU：BLE 订阅 + 光标 / 地球测试（打开测试页）
