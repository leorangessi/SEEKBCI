💡 SEEKBCI BLE 说明
• 固件：reference/SEEKBCI/SEEKBCI.ino（ADS1299 + BMI270）
• 协议 seekbci_eeg_v2：39 字节扩展 Cyton 包（8 路 EEG µV + IMU）
• 电量：固件周期上报 / 主机发 'p'；状态包 0xB0…0xC2
• BMI270：SDA=IO25，SCL=IO33
• 连接后 SSVEP / EMG 与 IMU 测试共用此链路
• 需后端安装 bleak
